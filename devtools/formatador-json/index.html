Formatador de JSON

Valida, formata e minifica JSON, apontando onde está o erro.

Sobre esta ferramenta

Cole um JSON para validá-lo, indentá-lo com 2 ou 4 espaços ou tabs, ordenar as chaves alfabeticamente ou minificá-lo para reduzir o tamanho. Quando há erro de sintaxe, a mensagem indica a posição aproximada.

Os números gerados são fictícios e servem apenas para testes e desenvolvimento. Não os utilize para fins fraudulentos.
