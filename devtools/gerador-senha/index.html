Gerador de senhas

Senhas aleatórias geradas com a API criptográfica do navegador.

    Sobre esta ferramenta

    Senhas longas e aleatórias são a melhor defesa contra ataques de força bruta. A geração usa crypto.getRandomValues com sorteio sem viés, e nada sai do seu navegador. Use um gerenciador de senhas para guardá-las.

    Os números gerados são fictícios e servem apenas para testes e desenvolvimento. Não os utilize para fins fraudulentos.
