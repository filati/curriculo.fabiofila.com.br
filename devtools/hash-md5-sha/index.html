Hash MD5 / SHA

Calcula MD5, SHA-1, SHA-256, SHA-384 e SHA-512 do texto digitado (UTF-8).

    MD5 e SHA-1 não são seguros para senhas ou assinaturas; use apenas para checksums e compatibilidade.

    Sobre esta ferramenta

    Funções de hash geram uma impressão digital de tamanho fixo para qualquer entrada, úteis em checksums e integridade. MD5 e SHA-1 estão quebrados para segurança: para senhas, use bcrypt ou Argon2 em vez de um hash simples.

    Os números gerados são fictícios e servem apenas para testes e desenvolvimento. Não os utilize para fins fraudulentos.
