Gerador de CPF

CPFs aleatórios com dígitos verificadores válidos. Apenas para testes.

    Gerador de CNPJ

    CNPJs aleatórios com dígitos verificadores válidos, no formato numérico ou no novo alfanumérico. Apenas para testes.

      Validador de CPF/CNPJ

      Cole um CPF ou CNPJ (numérico ou alfanumérico) e veja se os dígitos verificadores conferem.

      Gerador de UUID

      UUIDs v4 (aleatório) ou v7 (ordenável por data/hora, ótimo para chaves primárias).

        Gerador de senhas

        Senhas aleatórias geradas com a API criptográfica do navegador.

          Formatador de JSON

          Valida, formata e minifica JSON, apontando onde está o erro.

          Base64 / URL

          Codifica e decodifica texto em Base64, Base64URL ou URL (percent-encoding), com suporte a UTF-8.

          Testador de regex

          Teste expressões regulares (JavaScript) com destaque dos trechos encontrados e dos grupos de captura.

            Decodificador JWT

            Lê o cabeçalho e o conteúdo de um token JWT. A assinatura não é verificada.

              Hash MD5 / SHA
              
          
              Calcula MD5, SHA-1, SHA-256, SHA-384 e SHA-512 do texto digitado (UTF-8).
              
          
          
          
                
          
                MD5 e SHA-1 não são seguros para senhas ou assinaturas; use apenas para checksums e compatibilidade.
                
        
                
        
                
          
                Timestamp Unix
                
          
                Converte timestamp Unix (segundos ou milissegundos) em data e vice-versa.
                
          
                Agora:  
                
          
                Timestamp → data
