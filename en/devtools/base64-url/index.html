Base64 / URL

Encodes and decodes text as Base64, Base64URL or URL (percent-encoding), UTF-8 aware.

About this tool

Base64 represents bytes as ASCII text; Base64URL swaps + and / for - and _ for use in URLs and JWTs; percent-encoding escapes special characters in query strings. Conversion is UTF-8 aware, so accents and emojis work.

Generated numbers are fictitious and meant only for testing and development. Do not use them for fraudulent purposes.
