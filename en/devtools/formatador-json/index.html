JSON formatter

Validates, formats and minifies JSON, pointing out where the error is.

About this tool

Paste JSON to validate it, indent it with 2 or 4 spaces or tabs, sort keys alphabetically or minify it to shrink its size. On a syntax error, the message points to the approximate position.

Generated numbers are fictitious and meant only for testing and development. Do not use them for fraudulent purposes.
