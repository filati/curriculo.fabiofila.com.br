UUID generator

v4 (random) or v7 (time-ordered, great for primary keys) UUIDs.

    About this tool

    UUID v4 is fully random; v7 starts with a millisecond timestamp, which keeps rows ordered and reduces index fragmentation in databases. Values come from the browser's cryptographic API.

    Generated numbers are fictitious and meant only for testing and development. Do not use them for fraudulent purposes.
